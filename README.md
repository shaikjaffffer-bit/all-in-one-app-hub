# All-in-One App Hub

An all-in-one web application that provides quick access to different
services from one place.

## Features

- Shopping
- Grocery
- Food delivery
- Ride booking
- Movies and entertainment
- Travel
- Ticket booking
- App search
- Live clock

## Technologies Used

- HTML
- CSS
- JavaScript
